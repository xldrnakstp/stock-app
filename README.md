# 주식 레이더 — 거래량 급증 · 주가 정체 종목 스크리너 (한국 · 미국)

GitHub 클라우드에서 매일 자동으로 분석하고, 결과를 폰 앱(홈 화면 웹앱)으로 봅니다. PC를 켜 둘 필요가 없습니다.

## 매일 하는 일 (자동)

| 시각 (평일, 한국시간) | 내용 |
|---|---|
| 07:00 | 전체 분석: 한국·미국 스크리닝 + 종목 상세 분석 + 보유 종목 매도 점검 → 알림 |
| 16:10 | 보유 종목 점검 (한국장 마감 반영) → 새 매도 신호가 있으면 알림 |
| 앱에서 매수·매도 입력 시 | 보유 종목만 1~3분 안에 다시 점검 |

GitHub 일정 실행은 서버 사정에 따라 10~30분 늦어질 수 있습니다.

## 보안

- 보유 종목·리포트·알림 정보는 모두 **앱 비밀번호로 암호화**(AES-256)해서 `docs/data.enc`, `trades.enc`, `subs.enc`에 저장합니다.
- 저장소가 공개여도 비밀번호 없이는 내용을 볼 수 없습니다. 공개되는 것은 프로그램 코드뿐입니다.
- 비밀번호는 GitHub Secrets(`APP_PASSWORD`)와 내 폰에만 있습니다.

## 처음 설정

1. 이 폴더의 파일을 저장소에 업로드합니다.
2. **Settings → Secrets and variables → Actions → New repository secret**에서 두 가지를 추가합니다.
   - `APP_PASSWORD`: 앱 비밀번호 (8자 이상)
   - `DART_API_KEY`: DART 인증키 (한국 공시 확인용, 선택)
3. **Settings → Pages**에서 Source를 *Deploy from a branch*, Branch를 `main` / `/docs`로 정하고 Save를 누릅니다.
4. **Actions → Stock app → Run workflow**로 첫 분석을 실행합니다 (5~10분).
5. 앱 주소 `https://<아이디>.github.io/stock-app/`를 엽니다.
6. 앱 **설정**에서 GitHub 토큰을 입력하고, 기존 기록을 가져온 뒤, 폰으로 QR을 찍어 설치합니다.

## 조건 바꾸기

`config.py`의 숫자를 고치면 됩니다 (GitHub 웹에서 연필 아이콘 → 수정 → Commit).

- **거래량:** 최근 5일 평균이 직전 20일 평균의 3배 이상
- **주가:** 최근 20거래일 수익률 0~+5%
- **잡주 제외:** 시가총액, 주가, 거래대금 하한. 스팩·ETF·리츠 제외
- **매도 판단:** 손절 −7%, +10%에서 일부 익절, 이후 최고가 대비 −7% 하락 시 이익 보호 매도

## 파일

| 파일 | 역할 |
|---|---|
| `screener.py` | 종목 목록·시세 수집, 조건 판정 |
| `analysis.py` | 과거 신호 통계(상승 확률·보유 기간별 승률), 세력 이탈 지표 |
| `evidence.py` | 공시(DART/SEC)·수급(네이버)·공매도 |
| `report.py` | 종목 분석 카드·차트 |
| `trades.py` | 보유 종목 매도 시점 판단 |
| `app_build.py` | 클라우드 실행: 분석 → 암호화 저장 → 알림 |
| `cloud_crypto.py`, `cloud_push.py` | 암호화, 폰 알림 |
| `docs/` | 폰 앱 (GitHub Pages) |
| `.github/workflows/app.yml` | 자동 실행 일정 |

투자 판단의 참고 자료이며, 투자 결과의 책임은 본인에게 있습니다.
